MCCHANGES JAR GUIDE
===================

The mcchanges jar tells PackSquash which files of your pack are the same as the
game's files. PackSquash leaves those files out. This page says where the jars
come from. The full usage guide is docs/fork/USAGE.md.


1. GET A READY JAR
------------------

Download it from the Releases of https://github.com/mocny-gaz/mc-changes

  mcchanges-java.jar      Java Edition, many game versions
  mcchanges-bedrock.jar   Bedrock Edition, the newest releases

These jars hold only hashes (fingerprints) of the game files. They hold no game
files, so they are small.

Then set, in your options file:

  mcchanges_path = 'C:\amc\mcchanges-java.jar'
  mcchanges_version = '1.21.4'


2. BUILD OR UPDATE A JAR YOURSELF
---------------------------------

The script is not in this repository. It is build_mcchanges_jar.py, in the tools
folder of the mc-changes repository, and in your C:\amc\packsquash-tools\
01-mcchanges-builder folder. Its README explains every command. In short:

  python build_mcchanges_jar.py java
  python build_mcchanges_jar.py bedrock --count 5
  python build_mcchanges_jar.py java --full

Everything is written in C:\amc. The first command writes mcchanges-java.jar.
Run it again when new game versions come out: it continues from the downloads
that it already has. --full writes mcchanges-full-java.jar, which holds the
game files.


3. WHAT TO SHARE
----------------

Share the default jars (hashes only). Do not share a full jar. Its files belong
to Mojang, and GitHub can remove them after a complaint. I am not a lawyer.
Check Mojang's rules before you decide.
